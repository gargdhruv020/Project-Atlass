# CodeIgniter 3 Legacy Portal - Project Atlas

This directory contains the CodeIgniter 3 PHP portal for Project Atlas.

## Overview
- **Framework**: CodeIgniter 3.x
- **Role**: Legacy client portal providing report access, subscription viewing, and client management.
- **Database**: Connects to the shared MySQL database (`project_atlas`) using the credentials defined in environment variables.

## Directory Structure
- `application/`: Application code (controllers, models, views, configurations).
- `system/`: CodeIgniter core framework system files.
- `index.php`: Front controller entry point.
